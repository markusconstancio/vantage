Safety is the architecture

Single source of truth

Every agent resolves its target through scope.yaml. Anything not authorized is refused before a packet is sent.

Human-gated exploitation

The exploit agent isn't written yet — its guardrails (per-action confirmation, lab-only) are documented for review first.

Synthetic-only samples

Every report here is generated from a fabricated persona and a synthetic scan — no real person's data, no real target.

One CLI

# enumerate an authorized lab target, then report
python -m vantage recon 192.168.56.101 --json | python -m vantage report - --html

# score a subject's OSINT exposure
python -m vantage osint personas/jordan-rivera.yaml --html -o risk.html
